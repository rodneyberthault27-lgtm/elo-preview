Privacidade com clareza.

Versão de 15 de outubro de 2026

Arquivos usados no simulador

A edição de logos e imagens é feita no navegador. Esta versão não tem um servidor próprio para receber os arquivos enviados pelo usuário. Exportações são geradas no dispositivo. Evite usar equipamentos compartilhados para documentos confidenciais.

Armazenamento local

O editor guarda preferências de largura dos painéis e fichas de prévia no armazenamento local do navegador. As fichas podem incluir os dados digitados, como cliente e empresa. Você pode remover esses dados nas configurações de armazenamento do navegador para este site.

Hospedagem e imagens externas

O site é hospedado no GitHub Pages. O provedor pode tratar dados técnicos das requisições, como endereço IP e informações de acesso, conforme sua política. O catálogo pode solicitar imagens de fornecedores e, quando necessário, de um serviço de proxy de imagens em images.weserv.nl. Esses serviços recebem dados técnicos da conexão. Os artigos e o portal não usam fontes externas ou rastreadores de audiência.

Publicidade

Não há AdSense, cookies de publicidade ou análise de audiência ativados por este portal nesta versão. Antes de ativar esses serviços, será necessário atualizar esta página e implementar os mecanismos de informação e consentimento aplicáveis. Uma simples mensagem de cookies não substitui essa configuração.

Contato e solicitações

Use o canal do projeto para dúvidas. Ele é público; não inclua informações sensíveis. Consulte também a política de privacidade do GitHub.
